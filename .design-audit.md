## Design DNA (detected)

- **Stack**: Next.js 15 (App Router), React 19, Tailwind v4, Framer Motion 12, clsx + tailwind-merge. No icon mega-lib bloat.
- **Type**: Onest (geometric sans — all headings + body) + Hurricane (handwritten script) for signature accent words via `.display-italic` / `.font-script`. **No Inter/Roboto** (the earlier "Inter ×33" grep hit was a false positive — `setInterval`, `IntersectionObserver`, `AmbientInterlude`, etc.).
- **Color**: Forest green / ivory / brass-gold / charcoal, fully tokenized. Multi-theme system (editorial / modernist / cinematic / retreat) — production default is **retreat**.
- **Tokens**: color, spacing (`--spacing-xs…3xl`, up to 15rem), radius (`--radius-sm/md/lg`), shadow, transition — all CSS-variable driven, themed in `app/globals.css`.

## Competitor Benchmark

Against the 2026 luxury-hospitality field (Awwwards Hotel/Restaurant + Luxury collections; Mediaboom / Cloudbeds trend reads): the standard is **immersive video storytelling**, **editorial minimalism with heavy whitespace**, and **mobile-first thumb-navigation**; leaders (Aman, Belmond, Rosewood, The Hoxton, Casa Cook) add **"cinematic conversion"** — drone/ambient video + low look-to-book friction (sticky booking, rate transparency).

**Giovanni already lives in this language** — full-bleed video heroes, ambient interludes, swipeable carousels, editorial spreads, a signature script accent. Its theme tokens literally reference Aman/Belmond/Rosewood as north stars (`globals.css:43,99,156`). **The opportunity vs leaders is conversion plumbing + a11y polish, not aesthetics.**

## Critical Issues (fix immediately)

*None.* The one genuinely broken item — the invisible secondary CTA on dark panels (`spa` / `experiences`) — was fixed 2026-06-27 (switched `outline` → `light-outline`).

## High Priority (fix before shipping)

1. **Radius bypasses the themeable token system** — 53 literal `rounded-lg/md/xl` vs only 5 uses of `rounded-[var(--radius-*)]`. The system defines per-theme radius (modernist sets all radii to `0`), but pages hardcode `rounded-lg`, so a theme switch wouldn't propagate. Worst offenders: `app/spa/page.tsx:110`, `app/about/page.tsx`, `app/blog/page.tsx`, `app/dining/page.tsx`, `app/weddings/page.tsx`, `app/rooms/[slug]/page.tsx`. → swap literals for the radius var.
2. **Focus-visible styling is thin** — only ~4 files carry any `focus`/`focus-visible` rule. Custom interactive elements likely lack a visible keyboard focus ring: `app/experiences/ExperienceMarquee.tsx` (drag strip), `components/themes/retreat/BrandCarousel.tsx`, `components/themes/retreat/RoomCardImage.tsx` (clickable cards), `components/ui/GalleryLightbox.tsx`. → add a tokenized `focus-visible:ring` to all card-links and controls.
3. **No skip-navigation link** — `app/layout.tsx` has no "skip to content" anchor; keyboard users tab through the full header every page. → add a visually-hidden skip link.
4. **Sub-44px touch targets** — `components/ui/Button.tsx:70` `sm` = `h-9` (36px); header chips fall below the 44px mobile minimum. → bump `sm` to `h-11` on touch, or enlarge hit area.

## Nice to Have (polish)

1. **`hover:scale-105` in ~9 files** (`about`, `dining`, `experiences`, `ImageCard.tsx`, `GiovanniFamily`, `ADayHere`, `Stays`, `RoomCardImage`) — the one mild AI-ish hover tell. `ImageCard` already does a tasteful in-frame image zoom; standardize on that instead of scaling whole cards.
2. **Animation durations sprawl** 220ms→1400ms ad hoc — codify into the existing `--transition` token for a consistent house easing/tempo.
3. **All-sans heading stack** — Onest for every heading is a valid modern-boutique choice, but heritage-luxury peers lean on a serif display (Cormorant/Canela). Optional: introduce a serif for H1/H2; Hurricane already carries the signature.
4. **Conversion plumbing** (real gap vs leaders): no persistent/sticky "Book" affordance or rate transparency — 2026 benchmark for lowering look-to-book friction.

## What's Working Well (genuinely)

- **Zero AI-slop color tells** — `0` uses of `gray/slate/zinc/neutral/stone`, `0` default-blue, `0` purple gradients. Every color flows from `--color-*` tokens.
- **Bespoke type** — Onest + Hurricane script signature, `.display-italic` headline treatment. No Inter/Roboto anywhere.
- **Real token architecture** — full multi-theme system with tokenized color, spacing, radius, shadow, transition.
- **Craft animation** — custom GPU-transform marquee, swipeable brand/room carousels, IntersectionObserver crossfades, Aria video loops, ambient audio, a pre-hydration splash — and `prefers-reduced-motion` **is** respected (`globals.css`, `ClientLayout.tsx`).
- **Full image alt coverage** (45 `<Image>` / 64 `alt=`) and aria-labels on nav, footer, lightbox.
- **Dead-on industry fit** — video-forward, editorial, whitespace-rich: exactly the 2026 luxury benchmark.

## Recommended Actions (ranked by impact)

1. Tokenize radius (High #1) — restores theme integrity in one mechanical sweep.
2. Add focus-visible rings + skip link (High #2/#3) — biggest a11y lift, moves that 6 → 8.
3. Fix `sm` touch targets (High #4).
4. Standardize hovers on in-frame zoom; retire `hover:scale-105` (Nice #1).
5. Add a sticky "Book / Enquire" affordance for mobile look-to-book (Nice #4) — the one conversion gap vs leaders.

## Dimension Notes (evidence)

- **Design System Consistency 7** — Excellent color/spacing/shadow/font token discipline (0 generic-Tailwind color violations). Single deduction: radius literals (53 vs 5) bypass the themed `--radius-*` tokens.
- **Visual Hierarchy 8** — Clear focal points (full-bleed heroes, editorial spreads), `display-italic` + script accent build hierarchy, generous whitespace via the spacing scale.
- **Typography 8** — Distinctive, comfortable line-heights (1.7–1.85 body), meaningful weight use (Onest Light 300 display). Minor: no serif display register.
- **Color & Emotional Fit 8** — Strong dominant-accent relationship (forest/ivory + gold), psychologically aligned (green = nature/retreat, gold = luxury), dramatic dark panels. Watch low-contrast tertiary clay text on cream.
- **Animation & Interaction 8** — Signature, bespoke interactions; reduced-motion respected. Minor: `hover:scale-105` spots + duration sprawl.
- **Accessibility 6** — Strong on alt + reduced-motion + aria-labels; weak on focus-visible coverage, skip-nav, and small touch targets. The weakest dimension; mechanical to lift.
- **Originality 9** — Effectively none of the 12 AI-slop tells present. Genuinely bespoke.
- **Industry Alignment 8** — Matches the 2026 luxury benchmark closely; below top tier only on booking-flow friction reduction.
